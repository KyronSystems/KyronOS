Get a feel for the OS.

No desktop environment hiding the fundamentals. KyronOS boots into a VGA terminal and gives you a simple shell to interact with the system.

01

Boot

GRUB Multiboot2 gets the system running from an ISO on x86 PCs.

02

Shell

Navigate directories, create and edit files, inspect memory and devices, manage users, and control the machine.

03

Explore

Experiment with a RAM-backed filesystem prototype and the foundations of KyronOS itself.

What is already there

The project is intentionally close to the metal. These are the pieces currently forming the foundation.

⌁

VGA console

Scrolling, cursor tracking, keyboard input, Shift handling and Tab completion.

⌂

User homes

Users have home directories under /home, with ~ available in the shell prompt.

▦

KSFS foundations

KSFS superblock validation and a generic block-device interface are in place.

Try it yourself.

Build the ISO locally, then run it in VirtualBox. The project also supports EFI mode.

$ ./setup.sh
$ make iso
$ make run

Generated image
build/kyronos.iso

For EFI in VirtualBox: make run EFI=on. See the repository documentation for build requirements and platform details.
